项目方向：天玑 9500 设备适配 OpenClaw 框架，结合文心大模型实现移动端端云协同 AI 助手
技术栈：Android、Node.js、文心大模型 API、OpenClaw
1. 项目背景
当前 AI Agent 应用逐步从单纯对话聊天，转向可落地执行实际任务的个人助手方向。OpenClaw 作为开源 AI Agent 项目，自带会话管理、技能扩展、持久记忆、定时主动提醒等能力，能够完成信息检索、文档处理、日程管理等日常任务，适合做移动端个人助手载体。
联发科技天玑 9500 移动平台内置高性能 APU/NPU 算力单元，具备端侧 AI 推理能力，能够支撑轻量化 AI 服务稳定运行。
本项目计划将 OpenClaw 适配到天玑 9500 Android 设备，接入百度文心大模型 API 提供语言理解与生成能力，搭建端云协同的移动端 AI 助手。项目整体按实际开发节奏规划，所有开发、调试、材料提交工作均在2026 年 6 月 15 日前全部完成。
2. 项目目标
2.1 核心必做目标
完成 OpenClaw 移动端基础适配，部署 Gateway 核心服务，保证会话、技能调用、本地记忆、定时提醒基础功能正常可用。
接入百度千帆文心大模型 API，选用 ERNIE-4.5-Turbo 作为主力模型，复杂场景辅以 ERNIE-4.5，完成对话理解与任务规划能力对接。
落地三类基础可用场景：信息查询、文档内容摘要、日程待办提醒，满足赛事基础验收要求。
2.2 可选拓展目标
在时间和技术能力允许前提下，利用天玑 9500 NPU 部署轻量 OCR 模型，实现本地图片文字识别；同时适配移动端使用习惯，开发简易专属小技能，作为项目加分内容。
2.3 非开发目标
本次项目不做端侧大模型本地部署、不进行 Android 底层权限适配、不做多平台消息联动改造、不适配 iOS 系统，专注核心功能实现，控制开发难度，保证按期交付。
3. 技术方案设计
3.1 整体架构
项目采用端云协同轻量化架构：移动端依托 Termux 搭建 Node.js 环境，运行 OpenClaw 核心服务；本地负责会话管理、技能执行、记忆数据存储；云端调用文心大模型 API 完成语义理解、内容生成与任务决策。
3.2 Android 运行环境
依托自身安卓开发基础，本项目采用Android 原生环境结合 Node.js 移动端运行时方案，可自主配置移动端 Node 运行环境，适配项目依赖与后台驻留策略。无需依赖第三方简易终端工具做降级部署，可从系统层面规范权限管理、进程保活、目录访问等配置，适配更规范、扩展性更强，也便于后续功能迭代与性能调优。
3.3 OpenClaw 移动端适配处理
针对安卓手机运行特点做基础适配：
通过锁定应用后台权限，避免系统清理进程，保障服务长期在线；
选用系统公共文档目录，简化文件访问权限配置；
对 OpenClaw 做模块精简与按需裁剪，移除冗余插件，保留核心业务模块，合理控制移动端内存占用与资源开销。
3.4 文心大模型 API 接入
基于百度千帆开放 REST API 接口，通过密钥鉴权获取访问凭证，适配 OpenClaw 现有大模型调用格式。用户请求经框架转发至文心接口，返回结果后再回传给前端交互层，接口逻辑简洁，便于调试和后期维护。
3.5 数据持久化方案
采用 OpenClaw 自带本地文件存储方式，不额外部署数据库，将会话记录、用户记忆、技能操作日志以本地文件形式保存，满足基础持久化需求，同时降低配置复杂度。
3.6 核心技能规划
优先实现三个刚需基础技能：
信息查询：支持生活常识、学习知识、基础资讯类文字问答；
文档摘要：对纯文本内容进行精简总结，提炼关键信息；
日程提醒：支持手动添加待办事项，依托框架心跳机制实现定时主动提醒。
3.7 NPU 拓展方案
后续可选基于天玑 9500 自带 NPU 开发套件，接入轻量 OCR 模型实现端侧文字识别，识别结果再交由文心大模型做内容解析。仅做功能演示，不做深度性能调优。
4. 可行性分析
4.1 内存与运行条件
整套环境包含 Node.js 运行环境、OpenClaw 核心服务及本地存储资源，整体内存占用约 900MB，低于赛事 2GB 限制标准，天玑 9500 设备可稳定承载运行。
4.2 时间与开发可行性
项目分阶段推进，从方案提交、电脑端功能调试，到真机适配、视频录制、文档整理，完整周期覆盖 5 月 7 日至 6 月 15 日，节奏合理，无需高强度赶工，可按时完成全部提交要求。
4.3 稳定性与网络适配
精简冗余功能并配置后台常驻后，可实现连续运行 30 分钟无闪退。核心对话生成依赖网络调用文心 API，本地记忆、文件查看、定时提醒等功能可离线正常使用。
5. 项目亮点
部署门槛低，基于 Termux 即可完成手机端环境搭建，无需专业安卓开发基础，普通开发者可复刻实现；
采用端云分离思路，端侧承载服务与基础任务，云端承担大模型推理，平衡运行性能、开发成本与隐私性；
区别于普通聊天机器人，具备长期记忆和主动提醒能力，可落地日常办公、学习、生活辅助场景。
